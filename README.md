# Trabajo Final

Caso N°2

Descripción del Proyecto:

Este proyecto consiste en el desarrollo de una aplicación interactiva en Python utilizando Streamlit, cuyo propósito es realizar un Análisis Exploratorio de Datos (EDA) del dataset Telco Customer Churn. El objetivo principal es identificar patrones, tendencias y factores asociados a la fuga de clientes (churn) en una empresa de telecomunicaciones

La aplicación integra conceptos de programación y análisis de datos, como:

Manipulación y limpieza de datos con Pandas
Análisis estadístico descriptivo
Visualización con Matplotlib y Seaborn
Programación Orientada a Objetos (POO)
Construcción de interfaces interactivas con Streamlit
